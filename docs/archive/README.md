# Documentation Archive

Everything under `docs/archive/` is historical.

Do **not** use archived files as current build, TestFlight, App Store, deployment,
or rollback instructions.

Current authority:

- `/README.md` for exact Flutter commands and build-time defines
- `/RELEASE.md` for the release workflow
- `/AGENTS.md` for agent engineering policy

Archived documents remain useful for incident history and release archaeology.
